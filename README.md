# Customer Churn Prediction Model

This project uses machine learning to predict customer churn based on a telecom dataset. It includes data preprocessing, model training using Logistic Regression, and evaluation.

## Features
- Cleaned and preprocessed dataset (over 8000 features)
- Train-test split with 93.6% model accuracy
- Saved model (churn_model.pkl) for deployment
- Developed using JupyterLab and scikit-learn

## Getting Started
1. Clone the repository
2. Open churn_model.ipynb in JupyterLab
3. Run all cells to train and evaluate the model
